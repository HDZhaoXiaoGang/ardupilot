# STM32F405FC Flight Controller (精简版)

基于STM32F405RGT6微控制器的自定义飞控板配置，专为固定翼飞机设计。
**精简版配置，移除高级功能，专注于基本飞行控制功能。**

## 精简版说明 (2024年最新)

本配置已精简为轻量级版本，移除不必要的功能，专注于基本飞行控制：

### 精简内容
- ❌ 禁用DSHOT电调支持 (简化电调控制)
- ❌ 禁用电调传感器支持 (简化传感器配置)  
- ❌ 禁用BLHeli电调接口 (简化电调配置)
- ❌ 禁用SmartAudio功能 (简化视频发射机控制)
- ❌ 禁用MSP协议 (简化通信协议)
- ❌ 禁用脚本功能 (简化固件复杂度)
- ❌ 禁用陀螺仪FFT功能 (简化信号处理)
- ❌ 禁用视觉里程计 (简化导航功能)

## 硬件规格

### MCU
- **型号**: STM32F405RGT6
- **架构**: ARM Cortex-M4 
- **主频**: 168MHz
- **Flash**: 1MB
- **RAM**: 192KB
- **封装**: LQFP64

### 传感器
- **IMU**: MPU6500 (SPI1)
- **气压计**: SPL06 (I2C1)
- **磁力计**: QMC5883L (I2C1)
- **OSD**: AT7456E (SPI2)

## 编译说明

使用以下命令编译固件：

```bash
cd ardupilot
./waf configure --board STM32F405FC
./waf plane
```

生成的固件文件位于：`build/STM32F405FC/bin/arduplane.hex`

## 注意事项 - 参考inav配置

1. **电源供电**: 确保为飞控板提供稳定的5V/3.3V电源
2. **传感器连接**: I2C设备需要正确的上拉电阻
3. **PWM频率**: 默认支持50Hz-400Hz PWM输出
4. **调试接口**: 可通过SWD接口进行固件调试
5. **备用端口**: MS1-MS2可通过PINIO功能配置为额外控制功能
6. **定时器冲突**: S7已禁用避免与PB3的定时器冲突
7. **视频发射机**: 支持SmartAudio协议控制视频发射机
8. **MSP协议**: 支持MSP协议进行设备通信
9. **DSHOT电调**: 支持DSHOT150/300/600协议
10. **电调传感器**: 支持BLHeli32电调传感器数据
